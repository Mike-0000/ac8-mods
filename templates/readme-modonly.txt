{title} {version}  -  ACE COMBAT 8: WINGS OF THEVE (Steam)
Offline single player only.

This is the mod on its own, for a game that already runs UE4SS mods.
No UE4SS yet? Use the complete download instead.

INSTALL
  1. Close the game.
  2. Copy the "{folder}" folder from this zip into the Mods folder of your UE4SS.
     Usually that is one of:
       Game\Binaries\Win64\ue4ss\Mods
       Game\Binaries\Win64\AC8FOV\runtime\Mods      (installs based on "FOV Change")
     If Game\Binaries\Win64\override.txt exists, it names the UE4SS folder in use.
  3. Start the game the way you already do for your other mods.

  Nothing else to edit: the folder holds an enabled.txt, so UE4SS loads it without
  an entry in mods.txt or mods.json.
