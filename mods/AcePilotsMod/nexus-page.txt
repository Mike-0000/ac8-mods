=== NAME ===
Ace Pilots - Enemy AI Difficulty

=== SUMMARY ===
Tune enemy pilot rank, manoeuvre odds, aircraft agility and aggression with an in-game menu (F6) and six presets (F8). Complete download includes UE4SS; mod-only supports an existing setup. Offline single player only.

=== DESCRIPTION (BBCode) ===
[size=5][b]Ace Pilots[/b][/size]

Makes enemy pilots in ACE COMBAT 8 fly and fight harder, with an in-game menu to choose how much. Settings are restored when turned off. Version 0.1.0.

[b]Offline single player only.[/b]

[size=4][b]In-game controls[/b][/size]
[list]
[*][b]F6[/b] opens the menu. Use the mouse, arrow keys or gamepad; Esc closes it.
[*][b]F8[/b] cycles six presets: Off, All rank 5, Boosted 2, Boosted 3, Boosted 4, MAX, with a preset banner.
[/list]

[size=4][b]What you can change[/b][/size]
[list]
[*][b]Pilot skill[/b]: enemy pilot rank (5 is a named ace), how often pilots choose skilled manoeuvres and how rarely they choose lazy ones.
[*][b]Aircraft[/b]: turn rates and acceleration, missiles in the air per enemy, and how long pilots hold hard turns before blacking out.
[*][b]Aggression[/b]: remove waiting for a turn to attack; allow flares, evasion and taunt manoeuvres where the mission disabled them.
[*][b]Scope[/b]: aircraft only or ground and sea units too; optionally allies; the game difficulty at which manoeuvre changes start.
[*][b]Behaviour scripts[/b]: the chance a fighter type receives a harder behaviour script.
[/list]

[size=4][b]Install - complete download[/b][/size]
Includes UE4SS unmodified. No separate mod requirement. Use this download if you do not already have UE4SS installed.
[list=1]
[*]Close the game. In Steam, right-click ACE COMBAT 8 > Manage > Browse local files.
[*]Copy the [b]Game[/b] and [b]EasyAntiCheat[/b] folders from the zip into the game folder.
[*]In Steam > Properties > General > Launch Options, paste this exact line:
[code]cmd /d /c "set EOS_USE_ANTICHEATCLIENTNULL=1&& %command% -anticheat_settings=AC8_Offline.json"[/code]
[*]Start the game from Steam and use offline single-player modes.
[/list]

[size=4][b]Install - mod only[/b][/size]
For an existing UE4SS installation with offline launch already configured, copy the [b]AcePilotsMod[/b] folder into your UE4SS Mods folder. Its enabled.txt enables it; no mods.txt edit is needed. Keep the offline launch option above.

[size=4][b]Settings and limitations[/b][/size]
[list]
[*]Until acepilots.ini exists, the mod starts on All rank 5 and writes the settings file in its folder. Menu changes save automatically. File edits are picked up within a second.
[*]Agility above 2 can make enemies overshoot.
[*]Tested on Steam build [b]25201480[/b]. On a different build the native part stays off when game code differs; pilot rank and aggression switches still work.
[*]Log: acepilots.log in the AcePilotsMod folder.
[/list]

[size=4][b]Going back online[/b][/size]
Clear the Steam launch option and delete [b]Game\Binaries\Win64\dwmapi.dll[/b] before going online. The launch option above starts the game without Easy Anti-Cheat.

[size=4][b]Source[/b][/size]
The mod contains one native DLL, [b]acepilots_hook.dll[/b], built from this [url=https://github.com/Mike-0000/ac8-mods/tree/main/mods/AcePilotsMod/src]C++ source and build script[/url] using the Visual Studio 2022 C++ build tools.
